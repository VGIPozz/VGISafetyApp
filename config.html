Site safety tab

This tab opens The Violin Group site safety app for everyone in the channel, on desktop and mobile: job details on the home page, then each required safety form.

Submitted forms are sent to this flow, which saves the PDF and posts it in the channel. The address is stored with this tab only, and isn't shown to people using the form. Leave it blank if you only want crews to create PDFs.
This page only works when adding the tab inside Microsoft Teams.
